# Code duplication audit — ROI-ranked findings

> Generated by duplication audit (umbrella plan). Read-only audit; no code changed.

  1. Consolidate `mustCreateTask` / POST `/tasks` test helpers (5 variants, 40+ call sites)

| Score | Effort | Risk | Typical action |

## Findings (ranked)

### 1. `mustCreateTask` / POST `/tasks` test helpers — ROI 9/10 (High)

- **Location:** `pkgs/tasks/handler/handler_http_patch_contract_test.go` (L88–108), `handler_http_cycles_test.go` (L16–35), `handler_http_list_stats_contract_test.go` (L77–88), `handler_http_create_contract_test.go` (L14–33), `pkgs/tasks/store/facade_cycles_test.go` (L22–29)
- **Issue:** Five distinct helpers perform the same HTTP POST to `/tasks` with minor body variations. Every POST contract change must be updated in multiple places.
- **Proposed change:** Add `handler_http_test_helpers_test.go` with `postTask(t, baseURL, body)` and `mustCreateTaskID(t, ...)`, reusing existing `withCreateChecklist` from `handler_create_test_helpers_test.go`.
- **Effort / risk / blast radius:** 4–6 hours; low risk; ~70–85 duplicated LOC across handler + store tests; 40+ call sites.
- **Evidence:** Grep `mustCreateTask` hits 11 test files; same decode/assert pattern in each.

### 2. Git handlers: global vs project-scoped parallel surfaces — ROI 9/10 (High)

- **Location:** Project: `handler_git_repositories.go`, `handler_git_worktrees.go`, `handler_git_branches.go`. Global: `handler_git_global.go` (309 lines). Routes in `handler.go` L100–121.
- **Issue:** ~12 endpoint pairs share parse → store call → JSON map → `writeJSON` structure with only scope (project ID vs global) differing.
- **Proposed change:** Internal `gitHandler` helper with `withGitProject(r) (projectID, err)` and thin route wrappers; reuse existing `runGitReconcile` pattern from `handler_git_reconcile.go`.
- **Effort / risk / blast radius:** 2–3 days; medium–high risk (HTTP contract, ADR-0037); ~180–220 duplicated LOC.
- **Evidence:** 18 `(list|create|get|delete)(Global)?Git` handler methods; reconcile already shared.

### 3. `agentreconcile` git seeding duplicates `internal/gittest` — ROI 8/10 (High)

- **Location:** `pkgs/tasks/agentreconcile/git_test_helpers_test.go` (L17–51) vs `internal/gittest/gittest.go` (`SeedWorktreeTemp`, L126–132)
- **Issue:** Full reimplementation of git init, config, commit, and `CreateGitRepository` that already exists in `gittest`.
- **Proposed change:** Replace `seedAgentReconcileGit` with `gittest.SeedWorktreeTemp(t, st)`; keep `seedSecondWorktreeOnRepo` only if not generalizable.
- **Effort / risk / blast radius:** ~1 hour; low risk; ~45 duplicated LOC.
- **Evidence:** Side-by-side identical git init + store seed flow; comment references `facade_git_test.go`.

### 4. Web `git.ts` vs `gitGlobal.ts` fetch clients — ROI 8/10 (High)

- **Location:** `web/src/api/git.ts` (179 LOC), `web/src/api/gitGlobal.ts` (258 LOC), both exported from `web/src/api/index.ts`
- **Issue:** Parallel fetch → `apiErrorFromResponse` → parse modules differing only in base URL (`/projects/{id}/git` vs `/git`).
- **Proposed change:** `gitClient({ scope: "project" | "global", projectId? })` or shared `gitFetch(pathSuffix, init)`.
- **Effort / risk / blast radius:** 1 day; medium risk; ~100–130 duplicated LOC. Pairs with dead-code audit #1 if legacy git is removed.
- **Evidence:** Parallel `list*GitRepositories`, `create*`, `delete*`, `reconcile*` function pairs.

### 5. `CustomSelect` vs `SettingsSelect` — ROI 8/10 (High)

- **Location:** `web/src/components/custom-select/CustomSelect.tsx` (339 LOC), `web/src/settings/SettingsSelect.tsx` (698 LOC)
- **Issue:** Two parallel combobox implementations (portal, keyboard nav, listbox a11y) with ~20+ import sites each.
- **Proposed change:** Extract `BaseCombobox` (portal + a11y + keyboard) with styling/search variants; migrate Settings onto shared headless layer.
- **Effort / risk / blast radius:** 2–3 days; medium–high risk (a11y regressions); ~200–280 duplicated LOC.
- **Evidence:** Both use `createPortal`, `role="combobox"`, arrow/enter handling; Settings adds search + grouped rows.

### 6. Handler contract-test harness boilerplate — ROI 8/10 (High)

- **Location:** 23 files matching `handler_http_*_contract_test.go`; fragmented helpers across patch/create/drafts/list_stats
- **Issue:** Repeated `newTaskTestServer` + `defer srv.Close()` (~130+ usages), local `mustGetJSON`, `assertBareError`, doc-mirror envelope structs.
- **Proposed change:** `handler_contract_test.go` with `startContractServer(t)`, `assertHTTPError(t, res, raw, status, substr)`, shared envelope types.
- **Effort / risk / blast radius:** 1 day; low risk; ~200+ duplicated LOC aggregate.
- **Evidence:** 73 `defer srv.Close()` in contract tests; envelope structs duplicated per suite.

### 7. MSW git handlers triple layering — ROI 7/10 (Medium)

- **Location:** `web/src/test/handlers/git.ts`, `gitGlobal.ts`, `gitMsw.ts`; factories in `web/src/test/factories/git.ts`
- **Issue:** Same URL suffix routing rules duplicated with different base prefix (project vs global).
- **Proposed change:** `gitMswHandlers({ base: "/git" | projectBase })` parameterized by scope.
- **Effort / risk / blast radius:** 4–6 hours; low risk; ~60–80 duplicated LOC.
- **Evidence:** Parallel `if (url.endsWith(.../repositories))` trees in `git.ts` and `gitGlobal.ts`.

### 8. Compose payload parsing: drafts subset duplicates templates — ROI 7/10 (Medium)

- **Location:** `web/src/api/parseTaskApiDrafts.ts` (L15–52), `web/src/api/parseTaskApiTemplates.ts` (L80–128)
- **Issue:** Nearly identical field blocks for title, prompt, priority, checklist, runner, cursor_model, project; templates add status, depends_on, tags.
- **Proposed change:** `parseTaskComposePayload` as canonical; drafts call it and narrow type, or extract `parseComposePayloadCore`.
- **Effort / risk / blast radius:** 3–4 hours; low–medium risk; ~35–40 duplicated LOC.
- **Evidence:** Side-by-side identical field validation blocks.

### 9. Handler CRUD: `/task-drafts` vs `/task-templates` — ROI 7/10 (Medium)

- **Location:** `handler_task_drafts.go` (77 LOC), `handler_task_templates.go` (221 LOC)
- **Issue:** Same list/get/delete/save skeleton; store already uses `namedpayload` but handlers duplicate HTTP wiring.
- **Proposed change:** Shared `handleNamedPayloadList/Save/Get/Delete` with hooks for template-only compose validation.
- **Effort / risk / blast radius:** 1 day; medium risk; ~50–60 duplicated LOC.
- **Evidence:** Identical `parseBoundedLimit` → store → `writeJSON` and 204 delete pattern.

### 10. Template handler repeated compose validate/normalize — ROI 7/10 (Medium)

- **Location:** `handler_task_templates.go` L46–68 (save), L110–128 (patch), similar in instantiate L190–197
- **Issue:** Identical chain: `decodeComposePayload` → `GetSettings` → `validateComposePayload` → `composePayloadToRaw` repeated in same file.
- **Proposed change:** `(h *Handler) normalizeComposePayload(ctx, raw, settings) (json.RawMessage, error)`.
- **Effort / risk / blast radius:** 2 hours; low risk; ~36 duplicated LOC.
- **Evidence:** Byte-for-byte duplicate validation blocks in save and patch handlers.

### 11. Web draft vs template API clients — ROI 7/10 (Medium)

- **Location:** `web/src/api/tasks.read.ts` / `tasks.write.ts` (drafts), `web/src/api/taskTemplates.ts` (114 LOC)
- **Issue:** Same list/get/save/delete fetch boilerplate per named-entity resource.
- **Proposed change:** `namedEntityApi({ resource: "task-drafts" | "task-templates", parsers })`.
- **Effort / risk / blast radius:** 6–8 hours; low–medium risk; ~40–50 LOC per resource.
- **Evidence:** Identical `fetchWithTimeout` + `assertTaskPathId` + parse list/detail pattern.

### 12. `TemplateRow` reimplements `SavedEntityRow` — ROI 6/10 (Medium)

- **Location:** `web/src/tasks/components/saved-entities/SavedEntityRow.tsx` (87 LOC), `web/src/tasks/templates/components/TemplateRow.tsx` (190 LOC)
- **Issue:** Drafts use shared row; templates rebuilt click guards, exit animation, delete affordance, relative time separately.
- **Proposed change:** Extend `SavedEntityRow` with `leading`, `trailing`, `subline` slots; template checkbox/stepper as children.
- **Effort / risk / blast radius:** 6–8 hours; low–medium risk; ~50–70 duplicated LOC.
- **Evidence:** Both use row action exclusion helpers and `TaskListDeleteGlyph`; parallel CSS class patterns.

### 13. `handlertest` ↔ `handler_http_testserver_test.go` mirror — ROI 6/10 (Medium)

- **Location:** `internal/handlertest/server.go` (60 LOC), `pkgs/tasks/handler/handler_http_testserver_test.go` (86 LOC)
- **Issue:** Documented duplicate due to import cycle (whitebox tests cannot import `internal/handlertest`).
- **Proposed change:** Extract wiring to `internal/tasktestserver` imported by both (no handler import).
- **Effort / risk / blast radius:** 1–2 days; medium risk (import graph); ~55–60 duplicated LOC.

### 14. `map_*` domain↔model mappers — ROI 5/10 (Low)

- **Location:** 13 files in `pkgs/tasks/store/model/map_*.go`; 75+ `FromDomain`/`ToDomain` functions
- **Issue:** Repetitive field-copy boilerplate and slice-copy patterns across entity mappers.
- **Proposed change:** `go:generate` from struct tags, or shared `SliceMap` helper; already partially grouped in `map_drafts_templates.go`.
- **Effort / risk / blast radius:** 2–3 days; medium risk; ~500–700 aggregate LOC but low churn.
- **Evidence:** Repeated `append([]string(nil), d.Tags...)` pattern across mappers.

### 15. Confirm-dialog domain wrappers — ROI 5/10 (Low)

- **Location:** `web/src/components/feedback/ConfirmDialog.tsx` (base); wrappers in tasks, worktrees, projects (~6 files)
- **Issue:** ~25–35 LOC per thin wrapper delegating to shared `ConfirmDialog`; worktrees variant adds force-checkbox (legitimate).
- **Proposed change:** `confirmDialogPresets.deleteEntity({ noun, name, onConfirm })` for thin wrappers; keep git/worktrees custom.
- **Effort / risk / blast radius:** 4 hours; low risk; ~125 duplicated LOC aggregate.
- **Evidence:** All wrappers delegate to shared component; low bug surface today.
